Sante Diagnostics LIMS

A lab information system for a diagnostic centre, built by a team of three. I owned the administration and security side.

Group projectJava, JavaFX, PostgreSQLMy role: Super Admin module

The problem

A diagnostic lab handles patient records, samples and results, and every one of those needs controlled access. Staff must see only what their role allows, and the lab needs a trail of who did what.

Edit this to match your team's actual problem statement.

What I built

  • Secure login with passwords hashed using BCrypt, so they're never stored in plain text.
  • Role-based navigation so each user only sees the screens their role allows.
  • Audit trail that records important actions, so changes can be traced to a person.
  • User management where the Super Admin creates, edits and removes accounts.

What I learned

  • Why passwords are hashed and not encrypted, and how BCrypt makes guessing slow.
  • How role-based access works in practice, and how easy it is to leave one screen unprotected.
  • How to split one system across three people with a shared database without breaking each other's work.
