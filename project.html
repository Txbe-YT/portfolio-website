SafeText NG

A framework that catches financial scam messages written in Nigerian Pidgin, SMS and WhatsApp included.

Final-year project Solo In progress

The problem

Scam messages in Nigeria often mix English and Pidgin: "your acct don block, abeg verify your BVN." Existing scam detectors are trained on standard English, so they miss this kind of text.

People lose money to these messages, and there is no tool built for the way Nigerians actually write.

What it does

  • Uses a dataset I labelled myself, made of real-style Pidgin and code-switched scam and normal messages.
  • Trains a TF-IDF + SVM baseline to classify a message as scam or not.
  • Compares that baseline against transformer fine-tuning.
  • Serves results through a real-time web dashboard where you can check a message.

Screenshots

Technologies

Python, scikit-learn (TF-IDF, SVM), possible transformer fine-tuning, a web dashboard for real-time checks.

What I learned

  • Data quality decides everything. Labelling messages by hand taught me how inconsistent Pidgin spelling is.
  • Starting with a simple baseline gives you something to beat before you try heavier models.
  • Code-switching (English and Pidgin in one sentence) breaks tools that assume one language.
